# RG Infographic Guidelines

**Status:** Initial task guide. Apply global requirements from ../brand-principles.md.

## Information architecture
1. Define the communication objective: explain, compare, summarize, or educate.
2. Identify one primary message.
3. Group supporting facts into a logical sequence.
4. Preserve source notes, qualifications, and attribution.
5. Remove content that does not support the narrative.

## Visual construction
- Use a clear hierarchy: title, key message, content groups, supporting labels, sources.
- Use RG typography and approved color tokens.
- Use building-block geometry where it supports grouping or relationships.
- Use icons only when they improve comprehension; keep one coherent icon family.
- Keep illustration, photography, lighting, and material treatment consistent.
- Use whitespace to separate information groups.
- Avoid excessive cards, borders, shadows, gradients, and decorative arrows.

## Content integrity
- Preserve all supplied figures, units, dates, labels, and claims.
- Do not invent statistics or explanatory claims.
- Do not omit caveats that materially change interpretation.
- Verify spelling, punctuation, and text rendering.

## Deliverables
Prefer SVG or HTML/CSS for text-heavy and structured infographics. Provide PNG/JPG previews at the requested dimensions. Keep text and major elements editable where practical.

## QA
- The narrative can be understood in the intended reading order.
- Main message is visually dominant.
- All numbers and labels match the source.
- Typography and visual components are consistent.
- Sources and qualifications are visible.
- No text is clipped or unreadable.
