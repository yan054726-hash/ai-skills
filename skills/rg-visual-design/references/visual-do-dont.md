# RG Visual Do / Don't Reference

**Purpose:** Convert recurring AI visual failures into actionable review rules.  
**Status:** Initial guidance based on the user-provided example of an AI-generated multi-panel AnyDesk renewal advertisement. That example is a cross-brand failure reference, not an RG brand asset.

## Core lesson

Visual consistency is not achieved by using a limited color palette alone. It requires a coherent system for composition, typography, iconography, rendering, lighting, materials, spacing, and recurring components.

## DO

- Define one art direction before generating a family of assets.
- Establish a master reference and reusable component rules.
- Use a clear primary focal point and information hierarchy.
- Keep icon style, illustration style, lighting, perspective, and material treatment coherent.
- Use a restrained palette with explicit color roles.
- Keep CTA, logo treatment, typography, and spacing consistent across related assets.
- Use realistic imagery only when it supports the message and matches the chosen art direction.
- Place exact text and official logos in editable layout tools where possible.
- Review the complete asset family side by side.

## DON'T

- Do not combine unrelated 3D objects, flat icons, photography, glossy effects, and glow effects without an intentional art direction.
- Do not let every panel look as if it came from a different prompt or designer.
- Do not give every decorative object equal visual weight.
- Do not add arrows, calendars, shopping carts, circular symbols, or device mockups unless they communicate something necessary.
- Do not introduce extra accent colors merely to make one panel more eye-catching.
- Do not vary button, CTA, logo, and heading styles arbitrarily across a campaign.
- Do not rely on an image model to render exact logos, QR codes, or long Chinese copy.
- Do not use vague correction requests when a specific issue can be identified.

## Failure diagnosis from the supplied example

| Observed issue | Why it weakens the result | Corrective rule |
|---|---|---|
| Different rendering styles across panels | The panels do not read as one campaign | Define a single art direction and shared component system |
| Too many competing focal elements | The main renewal message loses priority | Select one primary focal point; demote or remove decorative objects |
| Inconsistent buttons and module layouts | No repeatable visual rhythm | Reuse CTA, spacing, and typography components |
| Mixed perspective, lighting, and materials | Creates a collage-like, synthetic appearance | Standardize object angle, light direction, shadows, and materials |
| Exact copy and QR code embedded in generated imagery | Text or code may become inaccurate or unscannable | Add exact copy and original QR asset in an editable composition workflow |

## Review method

1. Identify the primary message.
2. Mark every element competing with it.
3. Compare typography, iconography, rendering, and spacing across all panels.
4. Remove elements without a communication function.
5. Rebuild recurring components from shared specifications.
6. Validate exact copy, logos, data, and QR codes separately.

## Brand boundary

The example is AnyDesk campaign material. Its red palette, JD.com elements, QR code, and AnyDesk logo are not RG brand specifications. Use this example only to learn from cross-asset consistency failures. Apply RG colors and assets only to RG work.
